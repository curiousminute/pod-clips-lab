Website

This website uses no cookies, analytics or trackers, and it collects no personal data.

Pod Clips Lab Publisher

The tool signs in only the Pod Clips Lab account owner, using TikTok Login Kit. It reads only the basic profile information that posting needs (display name, avatar and posting limits), plus the scopes user.info.basic, video.upload and video.publish.

The TikTok access token is stored only on the owner's own computer and is used only to post the channel's own videos. The tool collects no data from viewers or other TikTok users, and it never sells, shares or uses data for advertising.

Revoking access

The owner can revoke access at any time in TikTok's settings under Security, then Manage app permissions. The stored token is then deleted.
